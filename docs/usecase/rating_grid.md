## Grading Rubric: Azure Master Architect Program

This rubric is designed to evaluate student submissions for a hands-on challenge involving **Solution Architecture**, **AI Technology**, and **Agentic AI**. Each category is scored from **Excellent (5 pts)** to **Needs Improvement (1–2 pts)**.

This rubric is structured to support **fair, consistent, and comprehensive evaluation** across multiple dimensions of software engineering.

---

## Design

| Criteria | Excellent (5 pts) | Good (4 pts) | Satisfactory (3 pts) | Needs Improvement (1–2 pts) |
|----------|------------------|--------------|----------------------|------------------------------|
| System architecture, modularity, scalability | Clear, well-documented architecture with modular components and scalability considerations | Mostly meets expectations with minor gaps | Basic implementation with limited effectiveness | Incomplete or poorly implemented |
| Use of design patterns | Appropriate and effective use of relevant design patterns | Mostly meets expectations with minor gaps | Basic implementation with limited effectiveness | Incomplete or poorly implemented |
| Security | Thoughtful implementation of security | Mostly meets expectations with minor gaps | Basic implementation with limited effectiveness | Incomplete or poorly implemented |

## Scoring Guide

- **Total Points**: 60  
- **Grade Bands**:
  - **A (54–60)**: Exceptional implementation and architectural rigor  
  - **B (48–53)**: Strong implementation with minor gaps  
  - **C (40–47)**: Adequate implementation with room for improvement  
  - **D/F (<40)**: Incomplete or insufficient implementation
